## 📖 About the Project

The **Pratik Abhang Portfolio** is a personal website created to present my professional profile, technical capabilities, development projects, and journey as a software developer.

It provides visitors with a central place to explore my work, learn about my skills, and discover ways to connect with me professionally.

The project uses core web technologies to deliver a browser-based portfolio without requiring a dedicated backend for its basic static website functionality.

## 🎯 Objectives

- Establish a professional online presence.
- Showcase development projects and technical skills.
- Present professional experience and learning milestones.
- Make it easy for recruiters, developers, and collaborators to explore my work.
- Provide convenient access to project repositories and professional profiles.
- Maintain a website that can be updated as my experience and projects grow.

## 🚀 Getting Started

### Prerequisites

You need:

- Git
- A modern web browser
- A code editor such as Visual Studio Code

No Node.js installation or package manager is required for basic static-site development unless additional tooling is introduced.

### 1. Clone the Repository

```bash
git clone https://github.com/pratikabhang/PRATIK-ABHANG-PORTFOLIO.git
cd PRATIK-ABHANG-PORTFOLIO
```

### 2. Run the Website Locally

**Option A — Open directly**

Open `index.html` in your browser.

**Option B — Use Visual Studio Code**

1. Open the project folder in VS Code.
2. Install the Live Server extension if necessary.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

**Option C — Use Python**

If Python is installed, run:

```bash
python -m http.server 8000
```

Visit [http://localhost:8000](http://localhost:8000) in your browser.

Stop the server with `Ctrl+C`.

## ☁️ Deployment

The repository links to a portfolio deployment on Vercel.

To deploy your own version:

1. Fork or clone the repository.
2. Make and test your changes locally.
3. Push the updated code to GitHub.
4. Import the repository into Vercel.
5. Configure the project for static website deployment.
6. Deploy and verify the generated URL.

For a plain HTML, CSS, and JavaScript website, a build command is generally unnecessary. Confirm the output directory and deployment settings against the current project configuration.
